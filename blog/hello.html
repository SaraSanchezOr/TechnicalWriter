Hello, World: I'm starting a blog

November 3, 2026

For years I've been writing so that other people can understand complex products. Manuals, guides, error messages, API documentation. Almost always, my name doesn't appear anywhere: good docs are like a good referee, you only notice them when something goes wrong. This blog is where I finally get to write in the first person. Spoiler alert: it's less formal.

What I'll write about

Mostly three things:

  • Technical writing and plain language: tricks, common mistakes and real examples.
  • What I learn about code, told by someone who didn't start out as a programmer.
  • How I build simple websites, from the first text to publishing.

Why now

To document software I had to learn to read it. First Git and GitHub, then APIs, then HTML, CSS and JavaScript. One day I realized I no longer just explained how things worked: I could also build them. This website is the proof, and this blog is the notebook where I'll keep telling the story, including the bugs. Especially the bugs.

If any of these topics interest you, or you have a project in mind, get in touch.
